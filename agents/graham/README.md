# 벤저민 그레이엄 에이전트

그레이엄(1894~1976)의 투자 원칙을 공개 자료로 재현하는 Claude Agent SDK 에이전트입니다. AI 재현이며 본인의 의견도 투자 조언도 아닙니다. 그는 1976년에 세상을 떠나 "지금 시장에 대한 그의 의견"은 존재하지 않습니다.

## 성장 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 기반 | 페르소나 지침, 버핏 주주서한에서 원문 대조한 인용 11개(`quotes.jsonl`) | 완료 |
| 2 사실·사례 | 인물·저서 사실(`facts.md`), 원칙 사례 8개와 증거 13개(`cases.jsonl`) | 완료 |
| 3 점검표·계산 | 방어적 투자자 7기준 점검, 그레이엄 수, 순유동자산(NCAV) 계산 도구 | 완료 |
| 4 평가 | 함정 질문 10개(`evals/`), 오프라인 테스트 14개 | 완료(채점은 모델 호출이라 미실행) |
| 5 표시·형식 | 머리글 `📘 **벤저민 그레이엄** · AI 재현`, 3줄 쉬운 말, 추정 표기 | 완료 |

## 구조·실행
버핏 에이전트와 같은 구조입니다(`persona/`, `graham_agent/`, `scripts/`, `tests/`).
```bash
cd agents/graham
uv venv && uv pip install -e ".[dev]"
python -m graham_agent "코카콜라를 어떻게 보세요?"      # 모델 호출: 비용이 생길 수 있음
python -m graham_agent --chat                            # 여러 턴 대화(비용 안내 후 확인)
python scripts/verify_quotes.py && pytest -q             # 비용 없음
```
원문 코퍼스는 `../buffett/corpus`(커밋 안 함)를 심볼릭 링크로 씁니다. 없으면 `cd ../buffett && python scripts/fetch_letters.py`.

## 한계
- 그레이엄 본인의 저서·강연 원문은 저작권 때문에 담지 못했습니다. 말은 버핏이 서한에서 인용·요약한 것만 씁니다.
- 방어적 투자자 7기준의 수치는 원서로 확인하지 못한 **프로젝트 기본값**입니다. 무료 데이터가 약 4년치뿐이라 "10년 연속" 같은 기준은 가능한 연수만 봅니다.
- 점검표와 그레이엄 수는 결론이 아니라 질문거리입니다. 금융·보험 업종은 맞지 않습니다.
