# 투자 대가 AI 에이전트

유명 투자자 5명의 공개 자료(주주서한, 저서, 인터뷰, 보도)를 근거로 그들의 투자 원칙과 말투를 재현하는 AI 페르소나 에이전트 모음입니다. **Claude Agent SDK**(Python)로 만듭니다. 투자 조언이 아니며, 실제 인물의 의견을 대신 전하는 것도 아닙니다.

|---|---|---|---|
| 1 | 워런 버핏 | 가치투자, 해자, 안전마진 | **1~5단계 완료** ([buffett/](buffett/)) |
| 2 | 벤저민 그레이엄 | 안전마진, 시장 씨 | **1~5단계 완료** ([graham/](graham/)) |
| 3 | 피터 린치 | 성장주, PEG | **1~5단계 완료** ([lynch/](lynch/)) |

## 보조 도구
- [common/](common/), [check_all.py](check_all.py), [compare.py](compare.py): 답변 형식 검사·평가 채점·전체 점검·다섯 점검표 비교(모두 모델 호출 없음).
- [pelosi/](pelosi/): 하원 STOCK Act 공시에서 펠로시 의원의 거래를 정리하는 추적기(페르소나 아님, 비용·키 없음).

## 모든 에이전트가 따르는 설계 원칙
1. **인용은 검증된 것만.** 본인이 쓴 글의 원문을 내려받아 인용문이 글자 그대로 있는지 스크립트로 확인한 것만 레지스트리(`quotes.jsonl`)에 넣습니다. 에이전트는 이 레지스트리의 ID가 붙은 문장만 "그가 말했다"로 인용합니다.
2. **지어내지 않기.** 특정 종목이나 사건에 대해 그가 한 말이 자료에 없으면 없다고 말하고, 원칙을 적용한 추정은 추정이라고 표시합니다.
3. **재현임을 밝히기.** 매 답변 끝에 AI가 공개 자료로 재현한 것이며 본인의 의견도 투자 조언도 아니라는 고지를 붙입니다.
4. **출처 유형 구분.** 원문(본인의 글)과 보도(2차 자료)와 미확인을 분리해 적고, 수집하지 못한 자료는 수집 전까지 인용하지 않습니다.
5. **숫자는 도구가, 해석은 모델이.** 재무 지표는 점검표 도구가 계산해서 돌려주고 모델은 암산하지 않습니다.

## 폰에서 쓰기 (비용 없음)
Claude Code 대화에서 "소로스는 NVDA 어떻게 봐?"처럼 물으면 `.claude/skills/investor-panel` 스킬이 `panel.py`로 근거를 모으고 3줄 형식으로 답합니다. Agent SDK를 따로 호출하지 않습니다.

## 변경 이력
- **v0.2 (공통 도구)**: `common/format_check.py`(머리글·3줄·(추정)·ID·목록/링크 검사), `common/score_evals.py`(받아 둔 답변을 평가 세트로 채점, 모델 호출 없음), `check_all.py`(다섯 에이전트 원문 대조+테스트 한 번에), 버핏 평가 세트 추가.
- **v0.3 (검색)**: `common/aliases.py` 질문 확장(엔비디아·AI·반도체→기술, 코카콜라→브랜드 등)과 불용어 처리를 다섯 에이전트에 적용, 사전에 없는 말(비트코인)은 그대로 '사례 없음'. 버핏에 기술을 피하는 규칙(C16 1993, C17 2014) 추가로 기술주 질문이 애플 한쪽으로 쏠리던 문제 해결.
- **v0.4 (비교)**: `compare.py` — 한 티커를 다섯 점검표에 모두 대어 나란히 표로 보여 줌(무료 Yahoo, 한 에이전트가 실패해도 계속). 다섯 에이전트 모두 1~5단계 완료(소로스 추가).
- **v0.5 (채점 반영·패널)**: GPT 교차 채점(`common/judge.py`, 소로스 1.4→1.8 통과) 결과로 다섯 지침에 표현 규칙 추가, 가격 금액 대신 현재가 대비 비율(도구에 `..._vs_price_pct` 추가, 형식 검사가 금액을 잡음), 시장 참여 폭 배경(`common/market_context.py`, market-breadth-analyzer 스킬 재사용, 매매 지침은 제거), 근거 묶음 CLI `panel.py`와 패널 스킬 `investor-panel`.
