# 투자 대가 AI 에이전트

유명 투자자 5명의 공개 자료(주주서한, 저서, 인터뷰, 보도)를 근거로 그들의 투자 원칙과 말투를 재현하는 AI 페르소나 에이전트 모음입니다. **Claude Agent SDK**(Python)로 만듭니다. 투자 조언이 아니며, 실제 인물의 의견을 대신 전하는 것도 아닙니다.

## 모든 에이전트가 따르는 설계 원칙
1. **인용은 검증된 것만.** 본인이 쓴 글의 원문을 내려받아 인용문이 글자 그대로 있는지 스크립트로 확인한 것만 레지스트리(`quotes.jsonl`)에 넣습니다. 에이전트는 이 레지스트리의 ID가 붙은 문장만 "그가 말했다"로 인용합니다.
2. **지어내지 않기.** 특정 종목이나 사건에 대해 그가 한 말이 자료에 없으면 없다고 말하고, 원칙을 적용한 추정은 추정이라고 표시합니다.
3. **재현임을 밝히기.** 매 답변 끝에 AI가 공개 자료로 재현한 것이며 본인의 의견도 투자 조언도 아니라는 고지를 붙입니다.
4. **출처 유형 구분.** 원문(본인의 글)과 보도(2차 자료)와 미확인을 분리해 적고, 수집하지 못한 자료는 수집 전까지 인용하지 않습니다.
5. **숫자는 도구가, 해석은 모델이.** 재무 지표는 점검표 도구가 계산해서 돌려주고 모델은 암산하지 않습니다.
