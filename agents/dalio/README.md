# 레이 달리오 에이전트

레이 달리오의 투자 원칙을 그가 서브스택에 공개한 글로 재현하는 Claude Agent SDK 에이전트입니다. **비공식 재현**이며 달리오가 직접 만든 공식 "AI 클론"과 무관합니다. 본인의 의견도 투자 조언도 아닙니다.

## 성장 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 기반 | 페르소나 지침, 서브스택 글 **원문에서 대조한 인용 18개**(`quotes.jsonl`) | 완료 |
| 2 사실·사례 | 인물·활동 사실(`facts.md`), 본인이 글에서 설명한 투자 사례 12개와 증거 18개(`cases.jsonl`) | 완료 |
| 3 점검표·계산 | 포트폴리오의 위험 기여도, 평균 상관, 환경별 비중, 최대 낙폭, 변동성 역수 참고 비중 | 완료 |
| 4 평가 | 함정 질문 10개(`evals/`), 오프라인 테스트 17개 | 완료(채점은 모델 호출이라 미실행) |
| 5 표시·형식 | 머리글 `🧭 **레이 달리오** · AI 재현(비공식)`, 3줄 쉬운 말, 추정 표기 | 완료 |

## 실행
```bash
cd agents/dalio
uv venv && uv pip install -e ".[dev]"
python scripts/fetch_posts.py                 # 서브스택 글을 corpus/에 내려받기(raydalio.substack.com 접근 필요, 무료, 커밋 안 함)
python scripts/verify_quotes.py && pytest -q  # 비용 없음
python -m dalio_agent "SPY:60,TLT:40 포트폴리오를 어떻게 보세요?"   # 모델 호출: 비용이 생길 수 있음
python -m dalio_agent --chat
```

## 점검표가 보여 주는 것
돈의 비중이 아니라 **위험의 비중**입니다. 예를 들어 주식 60%·채권 40% 포트폴리오는 최근 3년 데이터에서 위험의 약 76%가 주식에서 나옵니다. 종목 하나를 넣으면 위험 집중이 100%로 나오고, 그 종목이 주식·장기채·금과 같이 움직이는 정도(상관)를 함께 보여 줍니다.

## 한계
- 이 페르소나는 달리오의 현재 시장 전망을 새로 만들지 않습니다. 글에 있는 원칙만 전하고, 그의 구체적 전망과 정치 견해는 인용하지 않습니다.
- 올웨더의 자산별 숫자 비중은 그의 글에 나오지 않았습니다. 도구의 변동성 역수 비중은 단순 계산 참고값입니다.
- 책(『원칙』, 『빅 디트 크라이시스』)은 저작권과 이메일 구독 장벽 때문에 담지 못했습니다. 서브스택 RSS는 최근 글 약 20개만 제공해 그 범위만 원문 대조했습니다.
- 점검 기준값과 환경 분류는 프로젝트 기본값입니다. 최근 3년 일별 데이터 기준이며 과거가 미래를 보장하지 않습니다.
