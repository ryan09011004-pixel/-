# 조지 소로스 에이전트

조지 소로스가 직접 쓴 글(2013 학술 기고문)과 강연(2009 중앙유럽대학교 녹취)으로 그의 **투자 사고방식(오류 가능성·재귀성·붐-버스트)**을 재현하는 Claude Agent SDK 에이전트입니다. **비공식 재현**이며 본인의 의견도 투자 조언도 아닙니다. 정치·자선 주제는 일부러 다루지 않습니다.

## 성장 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 기반 | 페르소나 지침, 원문에서 대조한 **인용 21개**(`quotes.jsonl`, S01~S21) | 완료 |
| 2 사실·사례 | 인물·활동 사실(`facts.md`, 1992년 파운드 거래는 '미확인'), 사례 10개와 증거 15개(`cases.jsonl`) | 완료 |
| 3 점검표·계산 | 티커 하나의 200일선 이격, 12개월 상승, 가속, 변동성, 낙폭, 하락 비대칭 + 붐-버스트 단계 가설 | 완료 |
| 4 평가 | 함정 질문 10개(`evals/`), 오프라인 테스트 16개 | 완료(채점은 모델 호출이라 미실행) |
| 5 표시·형식 | 머리글 `🌐 **조지 소로스** · AI 재현(비공식)`, 3줄 쉬운 말, 추정 표기 | 완료 |

## 실행
```bash
cd agents/soros
uv venv && uv pip install -e ".[dev]"
python scripts/fetch_sources.py               # 원문 2개 내려받기(georgesoros.com, opensocietyfoundations.org, pdftotext 필요, 무료, 커밋 안 함)
python scripts/verify_quotes.py && pytest -q  # 비용 없음
python -m soros_agent "NVDA를 어떻게 보세요?"   # 모델 호출: 비용이 생길 수 있음
python -m soros_agent --chat
```

## 점검표가 보여 주는 것
가격이 추세에서 얼마나 멀어졌는지(200일선 이격), 상승이 가속인지, 변동성이 평소의 몇 배인지, 고점 대비 얼마나 빠졌는지를 계산해 **붐-버스트 단계 가설**(추세 진행 / 가속·과열 의심 / 황혼 의심 / 붕괴 의심)을 붙입니다. 기준값은 소로스가 정한 것이 아니라 프로젝트 기본값이고, 실적·신용 같은 기초 여건과 '오해가 무엇인가'는 숫자로 볼 수 없습니다. 목표 주가는 만들지 않습니다.

## 한계
- 소로스의 가장 유명한 거래(1992년 파운드)와 퀀텀 펀드 성과는 확보한 원문에 없어 '미확인'으로 두고 말하지 않습니다.
- 책(『The Alchemy of Finance』 등)과 인터뷰는 저작권 때문에 담지 못했습니다. 인용은 글 1편과 강연 1편 범위입니다.
- 생존 인물입니다. 이 페르소나는 그의 현재 의견을 대신하지 않습니다.
