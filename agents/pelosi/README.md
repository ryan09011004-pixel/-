# 펠로시 공시 추적기

미국 하원 **STOCK Act 공시**(하원 사무처 공개 자료)에서 낸시 펠로시 의원의 주식 거래를 정리하는 도구입니다. 비용·API 키·모델 호출이 없습니다. 투자 조언이 아니며, 위법이나 내부정보 이용의 근거도 아닙니다.

## 알아둘 점
- 거래의 상당수는 **배우자 명의**(공시의 `SP`)입니다. 도구는 소유자를 따로 표시합니다.
- 금액은 **구간**으로만 공개됩니다. 합계도 구간(최소~최대)으로만 말합니다.
- 공시는 거래를 안 날부터 45일 안에 내면 되므로 **늦게** 나옵니다. 도구가 거래일과 공시일 사이 지연 일수를 보여 줍니다.
- 이 도구는 "그 사람이 되는" 페르소나가 아니라 공개 자료 정리 도구입니다. 현직 정치인을 흉내 내 발언을 만들지 않습니다.

## 사용
```bash
cd agents/pelosi
python -m pelosi_tracker recent  --year 2026 --days 90      # 최근 공시된 거래
python -m pelosi_tracker summary --year 2026 --days 400     # 종목별 매수·매도·순매수 구간
python -m pelosi_tracker parse tests/fixtures/20035780.txt  # 내려받은 PTR(PDF 또는 텍스트) 파싱
pytest -q                                                    # 네트워크 없이 실행
```
`pdftotext`(poppler-utils)가 필요하고, 최신 공시를 받으려면 `disclosures-clerk.house.gov` 접근이 허용되어야 합니다.

## 구조
`index.py`(색인 XML에서 공시 목록) → `ptr.py`(PDF 텍스트에서 거래 행 파싱) → `analyze.py`(종목별 구간 집계, 지연 일수) → `cli.py`. 파서는 2026년 실제 공시 5건(거래 29건)과 줄 수가 모두 일치하는지로 검증했고, 테스트 픽스처로 들어 있습니다(공개 자료).

## 한계
- 공시 PDF의 줄 배치를 읽는 방식이라 양식이 바뀌면 거래 행 수가 어긋날 수 있습니다. 어긋나면 조용히 넘기지 않고 테스트에서 드러나게 했습니다.
- 소유자 코드는 SP(배우자), JT(공동), DC(자녀)만 다루고 빈칸은 본인입니다. 옵션 행은 자산 코드 `OP`로 구분합니다.
- 연례 재산공개 보고서(보유 현황)는 다루지 않습니다.
