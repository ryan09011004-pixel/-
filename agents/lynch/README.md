# 피터 린치 에이전트

피터 린치(마젤란 펀드 1977~1990)의 투자 방식을 공개 자료로 재현하는 Claude Agent SDK 에이전트입니다. AI 재현이며 본인의 의견도 투자 조언도 아닙니다.

## 성장 단계
| 단계 | 내용 | 상태 |
|---|---|---|
| 1 기반 | 페르소나 지침, 1996년 PBS 프론트라인 인터뷰 **원문에서 대조한 인용 16개**(`quotes.jsonl`) | 완료 |
| 2 사실·사례 | 이력 사실(`facts.md`), 린치가 직접 말한 투자 사례 12개와 증거 23개(`cases.jsonl`) | 완료 |
| 3 점검표·계산 | PEG(성장률 상한 50%), 빚, 순현금, 재고 대 매출, 기관 보유율, 6가지 종류 추정, PEG 1 가격 역산 | 완료 |
| 4 평가 | 함정 질문 10개(`evals/`), 오프라인 테스트 17개 | 완료(채점은 모델 호출이라 미실행) |
| 5 표시·형식 | 머리글 `🛒 **피터 린치** · AI 재현`, 3줄 쉬운 말, 추정 표기 | 완료 |

## 실행
```bash
cd agents/lynch
uv venv && uv pip install -e ".[dev]"
python scripts/fetch_interview.py                       # 원문을 corpus/에 내려받기(www.pbs.org 접근 필요, 커밋 안 함)
python scripts/verify_quotes.py && pytest -q            # 비용 없음
python -m lynch_agent "코카콜라를 어떻게 보세요?"          # 모델 호출: 비용이 생길 수 있음
python -m lynch_agent --chat
```

## 한계
- 린치의 책은 저작권 때문에 담지 못했습니다. 6가지 분류와 PEG 1 기준은 인터뷰 원문에 없고 책·2차 자료의 통념이라 **프로젝트 기본값**입니다.
- "아는 것에 투자하라"라는 표현은 이 인터뷰 원문에서 확인되지 않았습니다(가까운 문장: 보통 사람도 서너 개 회사는 아주 잘 안다).
- 점검표와 분류는 결론이 아니라 질문거리입니다. 무료 데이터가 약 4년치뿐이고, 금융업에는 맞지 않습니다.
